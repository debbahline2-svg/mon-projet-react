# 🎮 GameRent - Plateforme de location de consoles

## 📝 Présentation
Application web de location de matériel de jeux vidéo. Le projet utilise une architecture conteneurisée pour garantir la portabilité.

## 🛠️ Stack Technique
- **Frontend** : React.js (Vite)
- **Backend** : Node.js & Express (API RESTful en POO)
- **Bases de données** : SQLite (SQL) & MongoDB (NoSQL)
- **Infrastructure** : Docker & Docker Compose

## 🚀 Installation & Lancement
1. Clonez le projet.
2. Assurez-vous que Docker Desktop est actif.
3. Lancer la commande suivante à la racine :
   ```bash
   docker compose up -d
